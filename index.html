    About the monkey

    One simulated monkey sits at a typewriter and presses a random key, a to z or the space bar, every 0.3 seconds. Everyone who opens this page sees the same keystrokes at the same moment.

    Where the randomness comes from

    The letters come from drand, a public randomness beacon run by the League of Entropy (a group of organizations including Cloudflare and Protocol Labs). It publishes a new random value every 3 seconds, and nobody, including the author of this site, can know a value before it is published. Each value becomes 10 letters, which the page types about 3 seconds after publication, so no letter exists anywhere before the monkey types it.

    History

    A scheduled GitHub job saves finished letters as plain text files, only after they have been typed. They are derived from drand's public records, so anyone can recompute them from the open source code.

    Words, search and the timeline

    A word is a run of at least 3 letters between two spaces that appears in the ENABLE word list. Click a word in the sidebar to jump to it, use the search box to find any string of letters, and hover over any letters to see how many hours after the monkey started they were typed.

    Privacy

    This site sets no cookies, runs no tracking and stores nothing in your browser. Your browser does request data from GitHub Pages and from drand's public servers, so those services see your IP address as with any website.
